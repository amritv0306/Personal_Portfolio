                    🎯 GIT PR CREATION - QUICK CHECKLIST
════════════════════════════════════════════════════════════════════════════

Follow these 10 steps in order. Copy-paste commands from here to your terminal.

════════════════════════════════════════════════════════════════════════════

✅ STEP 1: Open Terminal in VS Code
   Press: Ctrl + ~

✅ STEP 2: Navigate to Portfolio Folder
   Command:
   cd /Users/amritverma/Claude/Projects/Personal\ Portfolio

✅ STEP 3: Check You're on Master
   Command:
   git status

   Expected: "On branch master"

✅ STEP 4: Create Feature Branch
   Command:
   git checkout -b feature/portfolio-implementation

✅ STEP 5: Verify New Branch
   Command:
   git status

   Expected: "On branch feature/portfolio-implementation"

✅ STEP 6: Stage All Files
   Command:
   git add .

✅ STEP 7: Verify Files Staged
   Command:
   git status

   Expected: "Changes to be committed" (20+ files)

✅ STEP 8: Create Commit
   Command:
   git commit -m "feat: Add premium personal portfolio website

- Built with Vite 5 and TypeScript 5
- 8 portfolio components
- Premium dark mode design
- 15+ smooth animations
- GitHub API integration
- Fully responsive design"

   Expected: "[feature/portfolio-implementation ...] feat: Add premium..."

✅ STEP 9: Push to GitHub
   Command:
   git push -u origin feature/portfolio-implementation

   Expected: "remote: Create a pull request for 'feature/portfolio-implementation'"

✅ STEP 10: Create PR on GitHub
   1. Go to: https://github.com/amritv0306/Personal_portfolio
   2. Look for banner: "Compare & pull request"
   3. Click it!
   4. Add title (see below)
   5. Add description (see below)
   6. Click "Create pull request"

════════════════════════════════════════════════════════════════════════════

════════════════════════════════════════════════════════════════════════════

🎯 AFTER PR IS CREATED:

   1. GitHub will show your PR with all files
   2. You'll see: "Able to merge"
   3. Scroll down, click: "Merge pull request"
   4. Click: "Confirm merge"
   5. Done! Your code is merged to master
